## 2. Current position

Contralyne is live at contralyne.com. Two things are already in place at no extra cost:

- **Domain split.** contralyne.com serves the marketing page only; the application runs on
  app.contralyne.com and is explicitly excluded from search engines. This is the correct
  structure and is already built.
- **Clean page structure.** The landing page has a proper heading hierarchy and clearly
  separated sections (Features, How It Works, Security, Contact).

However, the site is currently **crawlable but invisible**. Google can read the page, but has
almost nothing to work with. Specifically, the following are absent:

| Missing item | Consequence today |
|---|---|
| robots.txt and sitemap.xml | Google is not told what to index or when it changes |
| OpenGraph / Twitter card data | Links shared on LinkedIn or WhatsApp show a blank grey box |
| Share image | No visual when the site is shared — significant for LinkedIn outreach |
| Structured data (JSON-LD) | Google and AI assistants cannot classify what Contralyne is |
| Canonical URLs | Ranking signal is split between contralyne.com and www.contralyne.com |
| Per-page titles and descriptions | One generic description applies site-wide |
| Google Search Console / Analytics | No visibility into traffic, queries, or indexing errors |

---

## 3. Proposed scope of work

A one-time technical SEO foundation, delivered as code in the existing repository.

| # | Deliverable | Detail |
|---|---|---|
| 1 | Metadata rewrite | Keyword-targeted page title and meta description written for the US and UK market, aligned to the product's existing positioning |
| 2 | robots.txt + sitemap.xml | Generated correctly for the live domain; application subdomain excluded |
| 3 | OpenGraph + Twitter cards | Shared links render a proper preview card with title, description and image |
| 4 | Share image | A designed 1200×630 preview image matching Contralyne branding |
| 5 | Structured data (JSON-LD) | SoftwareApplication, Organization and FAQ markup — this is also what ChatGPT, Perplexity and Google AI Overviews read when describing the product |
| 6 | Canonical URLs + domain consolidation | www and apex domain unified so ranking signal is not split |
| 7 | Performance pass | Image optimisation and font loading, with before/after Lighthouse scores supplied as evidence |
| 8 | Google Search Console + Google Analytics 4 | Verified, sitemap submitted, and set up under **your** Google account so ownership remains with you |
| 9 | Handover document | One page covering what was done, how to check rankings, and recommended next steps |

**Estimated effort:** 8–12 hours
**Delivery timeline:** 3–4 working days from advance payment

---

## 4. Explicitly excluded

To keep expectations clear, the following are **not** part of this change request:

- ❌ Any guarantee of search ranking position, traffic volume, or lead count
- ❌ Content writing — blog articles, landing pages, case studies
- ❌ Backlink building or outreach
- ❌ Ongoing monthly optimisation, monitoring, or reporting
- ❌ Paid advertising (Google Ads, LinkedIn Ads) setup or management

### Please read this part carefully

This work makes Contralyne **findable and correctly understood** by search engines and AI
assistants. It is the foundation, and without it no other SEO effort can work.

It does **not**, on its own, place Contralyne on page one for competitive terms such as
"AI contract review". Those positions are earned through published content and inbound links
over a period of six to twelve months. Any provider offering guaranteed rankings at this
price point is not being straight with you.

We would rather state this plainly now than have it become a disagreement later.
